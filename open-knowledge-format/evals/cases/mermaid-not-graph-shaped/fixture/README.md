# strutils

Small, independent string helper functions. None of them call each other
or depend on one another's output.

* `Reverse(s string) string` - returns s with its characters reversed.
* `CountVowels(s string) int` - counts the vowels (a, e, i, o, u) in s.
* `Truncate(s string, n int) string` - returns the first n characters of s.
